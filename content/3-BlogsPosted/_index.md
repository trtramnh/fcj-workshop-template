>This section introduces the blog topics shared during the AWS First Cloud Journey program. The blogs cover AWS infrastructure, cloud-native architecture, and practical experiences gained throughout the learning journey and internship. Together, they summarize key concepts, best practices, and real-world applications of AWS services.

### [Blog 1 - How AWS Upgraded Amazon Cognito with Nearly Zero Downtime](3.1-Blog1/)

This blog summarizes how AWS upgraded Amazon Cognito to its next-generation infrastructure with almost zero downtime. It introduces the new capabilities of Amazon Cognito, explains the migration strategies adopted by AWS, and highlights engineering practices that ensure high availability and backward compatibility.

### [Blog 2 - Building a Scalable E-commerce Website on AWS](3.2-Blog2/)

This blog introduces a scalable cloud-native architecture for an e-commerce website on AWS. It explains how services such as Amazon Route 53, CloudFront, AWS WAF, Application Load Balancer, Amazon ECS, Amazon Aurora, Amazon ElastiCache, and CloudWatch work together to build a secure, scalable, and highly available web application.

### [Blog 3 - AWS Lessons and Cloud-Native Mindset from My Internship](3.3-Blog3/)

This blog summarizes practical AWS knowledge and cloud-native concepts learned during a real-world internship project. It covers Amazon S3 integration, AWS SDK for .NET, IAM, cost optimization, Pre-signed URLs, and cloud security best practices.
