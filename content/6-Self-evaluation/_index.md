### SELF-ASSESSMENT

Throughout my internship on the **Snaptics** project from **May 11, 2026 to August 07, 2026**, I had the opportunity to learn and apply Frontend development knowledge as well as AWS Cloud services to a real-world product.

I directly participated in building the user interface, completing system features, integrating APIs from the Backend, resolving UI bugs, and optimizing multi-device display experiences to get the product ready for testing and production environments.

### Key Contributions & Technical Highlights

#### 1. Frontend Interface Design & Development

* Directly participated in designing and developing the user interface for the **Snaptics** application, ensuring modern aesthetics and user-friendly experience.
* Built a responsive UI system that functions smoothly across various screen sizes (Desktop, Tablet, Mobile).
* Applied UI/UX design standards and optimized component structures for easy reusability and future scalability.

#### 2. Backend API Integration & Business Logic Management

* Collaborated closely with the Backend team to connect and integrate all RESTful APIs into the application interface.
* Handled asynchronous data flows, application state management, and strict API response error handling.
* Researched and integrated relevant AWS infrastructure services such as S3 (image/invoice storage), Amplify, and CloudFront to support efficient frontend distribution.

#### 3. System Optimization & Troubleshooting

* Analyzed and thoroughly resolved UI rendering issues, data rendering bugs, and user interaction response latency.
* Proactively proposed UI testing solutions and data loading stream optimizations to enhance application performance.
* Developed problem-solving skills, meticulously tested workflows before committing code, and assisted in product testing.
